# 固定操作规范 v1

1. 已有课程只读取配置与`pipeline plan`简短结果，不重新分析目录或扫描历史日志。
2. 已完成课程：`verify`后`pipeline freeze`；已固定且未变化：直接`pipeline run`，命中缓存后结束，不调用语义模型。
3. 新课：按实际信息`pipeline init`，视频获取交给`tools/video_download`。网页发现只在需要时进行，临时媒体地址保留在私有请求中。
4. 下载使用`background start --stage download -- ...`；下载完成后`pipeline run --lesson ...`执行固定本地与语义步骤。后台任务按AGENTS登记20分钟聊天心跳，随后结束当前轮。
5. 心跳只看job摘要及必要的阶段状态；有新进展、完成、失败或需要用户处理时回报，无变化保持安静；全部结束后停心跳。不要常驻聊天循环等待。
6. 固定流水线由脚本负责音轨、抽帧、VAD、ASR、OCR、时间轴与渲染。GPT只负责分段板书、record和报告，固定Terra medium。
7. 输入文本和图片直接提供给语义任务，不重复通读README、PLAN、历史日志或整课大文件。按需回查原图及单个时间段。
8. 进程成功、文件存在、语义JSON门禁三者同时通过才放行。原始识别与编修稿分开，保留存疑，不能声称逐字或逐帧人工校对。
9. 失败只排查对应阶段及有限日志；原视频、已完成ASR分段和有效模型检查点不重做。修改已有完整产物后先核对再freeze，不盲目覆盖。
10. 上传GitHub只提交代码、配置模板、说明及测试。outputs、legacy、凭据、签名请求、模型和运行日志留本地。
