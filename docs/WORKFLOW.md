# 固定流水线 v2

适用范围：已有访问权限的单路课程视频，macOS Apple Silicon、本地MLX Whisper与Apple Vision、Codex Terra medium。教材PDF支持选页解析及来源融合；课件解析仍为后续模块，配置课件时明确停止。

## 入口与职责

| 入口/模块 | 固定行为 |
|---|---|
| `pipeline init` | 创建课程配置及00—09阶段目录，不覆盖已有课程 |
| `download plan/fetch` | 浏览器发现与传输分开；校验、来源登记、断点续传 |
| `pipeline plan` | 输出本地阶段状态与冻结指纹是否有效，无模型调用 |
| `pipeline run` | 复用有效阶段；未完成工作默认后台执行，完成后校验并冻结 |
| `pipeline freeze` | 检查完整产物、完成门禁、指定模型与视频身份，保存指纹 |
| `background` | 独立监督子进程，20分钟写摘要、结束/失败立即保存结果 |
| `codex_runner` | 固定实际模型参数、输入与输出证据、完成门禁及任务缓存 |
| `board_review` | 每约30分钟提供完整ASR/OCR候选和图片，输出分段板书文字 |

## 执行顺序

原视频先经下载工具登记，再执行：

1. 音轨：FFmpeg单声道16kHz PCM。
2. 抽帧：约25秒选择一帧，记录实际PTS，按课程ROI裁剪。
3. VAD：整课语音区间。
4. ASR：按5分钟原视频窗口保存检查点；移除静音后转写，再映射回原视频时间。
5. OCR：所有板书裁剪图的原始识别；未完成的旧OCR另存，不拼接残缺JSONL。
6. 语义与输出：清理、毫秒时间轴、接触表、分段板书核对、record编修、报告、离线HTML、文件检查。

原始输入不可原地替换。每个不同视频使用独立课目录。暂停后复用已有有效产物；人工修订与识别原稿分别保留。

## 节省token的机制

- 常规调用走固定脚本，不让模型重新规划流程。
- ASR/OCR、文件检查、监督和缓存使用本机代码，不调用GPT。
- 长任务开始后结束聊天轮次，20分钟App心跳仅读摘要，无变化不汇报，不循环sleep或tail。
- 分段完整输入避免读取大文件被截断；子任务不重复读项目长文档。
- 已完成课程冻结后，重复运行只检查本地文件；缓存验证测试断言没有启动worker。
- 模型任务仍保留准确性所需的来源，不通过丢弃存疑或删掉后半课来减少上下文。

## 完成与缓存边界

本地结构检查通过不等于识别准确。语义门禁须明确completed并确认覆盖，不能只凭退出码或文件存在。所有成功模型调用保留实际参数和输入证据。

冻结指纹记录课内相对路径、小文件内容散列及大媒体的大小/修改时间，目录重命名不会单独触发重做。第一次冻结核对视频SHA-256，后续视频状态相同可复用该身份检查。运行时指纹不同且存在完整产物会停止，要求先核对变化；不会自动覆盖正式record。

当前提供固定通路与显式失败交接，以及明确选页后的教材融合；尚不包含通用队列系统、并行GPU调度、任意平台自动登录或自动教材选页。App聊天回报由Codex实际登记；CLI单独运行只产生本地摘要。下载到流水线的接续由本地监督器完成，不依赖心跳。

教材解析产生物理页/印刷页索引、文字候选及关键页面图。报告和教材门禁、链接检查通过后清理课内音视频，保留删除前SHA-256、音轨时长与来源记录。原教材和图片、转写不删除。媒体已清理的完成课程可继续验证并命中缓存。
