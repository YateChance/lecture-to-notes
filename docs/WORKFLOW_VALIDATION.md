## 模型执行与完成条件

配置固定`gpt-6.1-terra`、`medium`，见`configs/default.yaml`和`.codex/config.toml`。执行器`src/lecture_agent/codex_runner.py`每次显式传入模型与推理强度；本课7个已完成语义任务均保留prompt、实际输入图片名单、命令、事件、最终响应及完成检查点。执行记录中的绝对路径保留当时的`待整理`目录；所有处理结束后才重命名为当前核心内容目录。

本地ASR/VAD/OCR使用本机运行环境，无需OpenAI API token；语义任务使用已登录的Codex账号。模型配置不会更改当前聊天本身的模型。

语义任务须同时满足进程成功、指定文件存在、JSON完成门禁通过。首轮整课长文件读取被工具截断，模型标注未完成；该轮结果未被采纳，保留在该课`_runs/workflow_validation/initial_incomplete/`。后续改为按时间段直接提供完整输入，防止“生成了文件”被误当成“核查完成”。任务缓存也会重新检查当前完成门禁。
